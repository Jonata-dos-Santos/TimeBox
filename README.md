# Temporizador-de-Foco
Um programa que serve como um Temporizador que salva o tempo restante em um arquivo sempre que o programa é finalizado antes do tempo definido acabar. O tempo é definido pelo usuário em uma janela; ao apertar o botão "Começar", ele inicia a contagem regressiva. O app pode ser customizado, permitindo ao usuário mudar o tema e a cor padrão do app.
