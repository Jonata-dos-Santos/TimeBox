# TimeBox
Um programa que serve como um Temporizador que salva o tempo restante em um arquivo sempre que o programa é finalizado antes do tempo definido acabar. O tempo é definido pelo usuário em uma janela; ao apertar o botão "Iniciar", ele inicia a contagem regressiva. O programa pode ser customizado com o tema claro ou escuro; o tema é definido de acordo com o tema do sistema do usuário, ou caso ele pressione o botão de mudar de tema no canto superior direito. O usuário pode customizar o som que toca quando o temporizador chega em 00:00:00 substituindo o arquivo "Som_Alerta.mp3" por outro com o exato mesmo nome (nota: deve ser um arquivo com a extensão ".mp3")
